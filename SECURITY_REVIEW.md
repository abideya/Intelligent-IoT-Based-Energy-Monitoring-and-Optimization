# Before publishing

- [ ] Inspect every screenshot and report page for API keys, access tokens, passwords and personal information.
- [ ] Confirm that the datasets, report, screenshots and demo video may be shared publicly.
- [ ] Keep credentials outside the repository (environment variables or an untracked `.env`).
- [ ] Confirm model/scaler/threshold pairs belong to the same experiment.
- [ ] Add a license only if publication rights are clear.

The image named `secret key` from the original archive was deliberately excluded from this package because it may contain a credential.
